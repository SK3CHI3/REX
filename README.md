# PoliceBrutalityTracker

**Justice through visibility.**

Mapping police incidents across Kenya's 47 counties. Real-time tracking, community reporting, transparent data.

[**Visit Live Site →**](https://policebrutalitytracker.co.ke)

---

## What We Do

We document and visualize police incidents to promote accountability and justice. Citizens report. We map. Data drives change.

**819+ cases tracked** across every county in Kenya.

---

## Built With

`React 18` · `TypeScript` · `Vite` · `Tailwind CSS` · `Supabase` · `PostgreSQL` · `React Leaflet`
